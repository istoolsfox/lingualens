## 踩坑记录

1. **pnpm 11 供应链策略**：esbuild postinstall 被拦；白名单新家在 `pnpm-workspace.yaml` 的 `allowBuilds`（package.json 的 `pnpm.onlyBuiltDependencies` 已废弃不读，WARN 会提示）。
2. **MV3 content script 不支持 ESM**：必须单文件 IIFE——独立 vite.content.config.ts 构建，浮动栏样式走 JS 字符串注入 Shadow DOM，不引 CSS 文件。
3. **TS `in` 收窄对可选属性失效**：`'x' in a && a.x` 后 a.x 的元素类型仍是 unknown → map 回调 implicit any；改用 `as Partial<AnalysisResult>` 直取。
4. **模板占位符漂移**：promptBuilder 注入 `{{MODE_HINT}}` 但模板没写占位符——被 promptBuilder 快照式测试抓出（这正是给它配测试的原因）。
5. **storage.session 默认仅 SW 可信上下文可访问**：Panel 侧不直接读 session，一律走 GET_STATE 消息（当前实现已遵守）。
6. **pnpm exec tsc 在 exec 前会跑 deps-status-check**：首次 `pnpm exec` 失败真相是 install 的构建脚本未放行，不是 tsc 本身的问题。
