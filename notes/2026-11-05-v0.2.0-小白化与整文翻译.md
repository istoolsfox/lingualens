# v0.3.0 全文注入与缓存复用轮（2026-11-05 追记）

## 用户需求 → 落地

| 需求                                 | 实现                                                                                                                                                                                                                 |
| ------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Mac 适配（没有 Alt）                 | manifest commands 平台分键：default Alt+L / mac ⌘⇧L；应用内快捷键展示按平台（⌃⌥ vs Ctrl+Alt）                                                                                                                        |
| 自定义按键                           | **应用内录键器**（设置页点"自定义按键"→按组合键→自动保存），绑定全文翻译注入；Chrome command 那条仍走 chrome://extensions/shortcuts                                                                                  |
| 删日/夜间切换                        | Header 主题按钮删除、设置页主题下拉删除；applyTheme 固定 dark（theme 字段保留兼容旧数据但失效）                                                                                                                      |
| 页面重设计（用我的 resource）        | 读了 website-styles DESIGN-SYSTEM §15 品类速查：AI/效率工具 → **G 暗色应用壳（kimi）**；tailwind 色板换 G tokens（暖黑 #121212/#181817/#1e1e1e 纵深 + 84% 白主文字 + kimi 蓝 #1a88ff + 小圆角工具感 + 层级不靠阴影） |
| 知识库自定义存储                     | File System Access API：设置页选备份文件夹 → 句柄存 IDB → 自动备份开关（库变更静默写 lingualens-backup.json）+ 手动立即同步；默认浏览器本地（Win/Mac 一致）                                                          |
| URL 全量匹配缓存                     | articles store（keyPath=url，LRU 100 条）：指纹（FNV-1a 段落序列）相同 → 秒出缓存 0 token                                                                                                                            |
| 内容变化重新翻译                     | 指纹不同 → 段落级 memo 复用（textKey=hash+长度双校验）→ 只翻新/变段落；UI 黄条"复用 X 段，新译 Y 段"                                                                                                                 |
| 强制翻译全部内容（含标题栏等）       | **全文注入模式**：TreeWalker 收集主框架全部可见文本节点（跳过代码/表单/隐藏/自身注入）→ 按父元素聚合单元 → 批译（2400/批）→ 译文注入原文下方（浅蓝左边线小字）                                                       |
| 译文放哪：先全量翻，特殊讲解注入原文 | 全文模式=译文注入原网页 + AI 挑讲解点（expr 必须是单元子串，SW 侧防御校验）→ 原文**虚线下划线** → 点击弹 Shadow DOM 讲解卡（意思+为什么+一键深度精读进侧边栏）；正文模式仍走侧边栏双语对照                           |
| 入口                                 | 浮动栏新增「全文」按钮 + 应用内自定义快捷键（默认 Ctrl+Alt+L / ⌃⌥L）+ 进度 pill（点击清除全部注入）                                                                                                                  |
