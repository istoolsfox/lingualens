# v0.2.0 小白化与整文翻译轮（2026-11-05）

## 用户反馈与处理

| 反馈 | 根因/处理 |
|------|-----------|
| API 配置好了但不行 | 未复现到具体错误（用户未给报错截图）。做三层处理：①厂商预设消除"BaseUrl 填错路径"这一最大嫌疑；②"保存并测试"一键先存后测（此前密钥没点保存就不生效，是隐藏坑）；③错误文案具体化（bad_request 提示厂商模型是否匹配）。若 v0.2 仍复现，要用户提供设置页测试按钮的报错文案 |
| 想选厂家而不是填链接 | 8 家预设 + 自定义；选完自动填 baseUrl + 推荐模型，用户只填 Key |
| 面向小白 | 设置页三步流（选厂商→贴密钥→保存并测试）；改动自动保存（防抖 500ms）；高级项收进折叠 |
| 快捷键不冲突 + 可自定义 | Chrome commands API（全局层接管，站内冲突不可能）；默认 Alt+L；设置页"修改快捷键"直达 chrome://extensions/shortcuts |
| 快捷键自动翻"本文的文章"而不是全站 | Readability 正文提取（p/h/li/blockquote/pre，过滤 <2 字符），60000 字上限；分批 2400 字顺序翻译；ArticleView 双语逐段对照+进度条+停止 |
| 选中过多文字不翻译 | **实锤根因 `content/index.ts` 旧 76 行：选区 >2000 字符直接 return null，浮动栏根本不出现**。修复：12000 字上限内截断照常浮动+黄色"长文已截断"提示条；>4000 字触发 prompt 精简指令（语法/词汇各限 3 条）防输出截断；maxTokens 默认 4096→8192 |
