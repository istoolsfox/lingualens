10 断言：配置连接→弹窗渲染→全文注入 8 段真译文→无残留转圈→显隐 0 新请求→article 侧栏双语→复用提示→pill 完成态。截图 notes/e2e/01-05。

**基建踩坑（下次直接抄）**：
1. Chrome 137+ 系统 Chrome 移除 `--load-extension`（`DisableLoadExtensionCommandLineSwitch` flag 也无效，Chrome 156 实测）→ 必须用 **Playwright 自维护 Chromium**（channel:'chromium'）
2. 扩展加载需 headed + `launchPersistentContext(独立临时 userDataDir)` + `--disable-extensions-except/--load-extension`
3. `page.evaluate` 跑在主世界拿不到 chrome.runtime——扩展 API 操作经 popup 页上下文执行
4. 断言只认真译文文本节点（失败占位文本会冒充 data-ll 节点造成假阳性，本轮真踩）
5. fake-server 抽段落 JSON 用**括号配平**不用 lastIndexOf（schema 契约的 ']' 会干扰）
