# ROADMAP —— 开发阶段规划

> 版本 v0.1（2026-11-05，阶段 1 产出，待确认）
> 阶段式开发，每阶段有明确产出与验收标准，验收不过不进下一阶段。

## 阶段总览

```
阶段 1  需求与架构（本文档集）          ← 当前，待确认
阶段 2  扩展基础框架（能选中、能开侧边栏）
阶段 3  AI 分析核心（四模式结构化分析）
阶段 4  连续追问（多轮对话）
阶段 5  知识库（收藏/搜索/导入导出）
阶段 6  学习训练（测试/仿写）
阶段 7  整体测试与交付
```

依赖关系：2 → 3 → 4；5 可与 4 并行（存储层独立）；6 依赖 3+5；7 收尾。

---

## 阶段 2：浏览器扩展基础框架

**范围**：Manifest V3 工程脚手架；content script 选区监听与快照；浮动工具栏（Shadow DOM）；Side Panel 打开与基础布局；SW 消息路由；设置页骨架 + API 配置表单。

**不做**：真实 AI 调用（阶段 3）。

**验收**：
- 在 Hacker News、GitHub 等真实网页选中文字，浮动栏 <300ms 出现且样式隔离。
- 点击「AI 精读」打开侧边栏，快照（文本/URL/标题/上下文）完整传递到侧边栏展示。
- chrome:// 页面选中无浮动栏，图标入口可打开侧边栏并提示使用手动输入。
- 设置可保存并重开浏览器后读取；主题切换生效。

## 阶段 3：AI 分析核心

**范围**：AI 客户端（超时/重试/取消/防重复）；模式路由；四模式 prompt 模板 + JSON 契约；四级降级解析；结构化结果渲染（概览/结构/语法/词汇/搭配/表达六个 Tab）；流式渐进渲染；错误三态。

**验收**：
- 配置真实 OpenAI 兼容端点后，PRD 四大验收案例全过（逐条核对必须讲清的点）。
- 单词/短语/句子/段落各选一个真实网页文本验证模式路由正确。
- 断网/错 Key/超时三类故障均有明确错误态与重试入口。
- 解析降级：喂入带脏输出的 mock 响应，UI 不白屏、有"简化视图"角标。

## 阶段 4：连续追问

**范围**：对话管线（继承原文+分析摘要+历史滚动窗口）；对话 Tab 渲染；流式输出与中断；快捷追问入口；重新分析重置对话。

**验收**：
- 对同一英文句子连续追问至少 5 个不同角度问题（为什么用 X 不用 Y / 构词 / 换表达 / 给例句 / 简单英语重讲），回答均基于原文且不重复整句分析。
- 中断生成后已渲染内容保留；重新分析后对话正确重置。

## 阶段 5：知识库

**范围**：IndexedDB 存储层（favorites）；一键收藏（含/不含分析两路径）；列表/筛选/搜索；删除；导入导出 JSON；清除全部数据。

**验收**：
- 收藏 → 重启浏览器 → 数据完好。
- 千条假数据下搜索 <100ms；导入已有备份正确去重；清除后三端状态归零。

## 阶段 6：学习训练

**范围**：基于收藏的测试生成（单词理解/短语含义/语法选择/翻译）；仿写练习与批改；练习记录（P2 可延）。

**验收**：
- 从收藏的句子生成一组 5 题测试，题目与收藏内容强相关，答案与解析正确。
- 仿写练习：给出原句结构 → 用户作答 → AI 批改指出表达问题并给改进版（PRD 第七节流程走通）。

## 阶段 7：整体测试与交付

**范围**：全链路 E2E（Playwright + mock 端点）；对抗样例（prompt 注入）回归；性能与内存检查；文档齐备。

**交付物**：
- 完整源代码（TypeScript strict 零错误，测试通过）
- README（安装说明 + 配置说明 + 开发指南）
- 测试报告（单元/E2E/真实模型验收案例结果）
- 已知问题清单（诚实记录兼容性与体验限制）

**验收**：
- 全新 Chrome profile 加载扩展 → 从安装到完成一次"选中→精读→追问→收藏→重启验证"全旅程无阻断。
- 四大验收案例在最终构建上复验通过。

---

## 阶段节奏约定

1. 每阶段开始前：回顾上一阶段验收遗留问题。
2. 每阶段结束：git 提交（阶段名入 commit message）+ 验收记录写入 `notes/`。
3. 任何阶段发现的需求变更回写 PRD/FEATURE_LIST 并标注版本。
