# FEATURE_LIST —— 功能拆解

> 版本 v0.1（2026-11-05，阶段 1 产出，待确认）
> 优先级定义：P0 = 第一版必须有；P1 = 第一版应该有；P2 = 预留/后续版本。
> 每条功能含验收要点，阶段归属见 `ROADMAP.md`。

## A. 选区捕获与浮动工具栏

| #   | 功能                                                      | 优先级 | 验收要点                                                                       |
| --- | --------------------------------------------------------- | ------ | ------------------------------------------------------------------------------ |
| A1  | 选中英文文本后出现浮动工具栏（精读 / 翻译 / 解释 / 收藏） | P0     | mouseup 后 <300ms 出现，位置贴选区，不遮挡选中文本                             |
| A2  | 选区即时快照（文本 + 前后上下文 + URL + 标题）            | P0     | 浮动栏点击时选区已丢失仍能正常工作；iframe 内选区可捕获（同源）                |
| A3  | 浮动栏用 Shadow DOM 隔离样式                              | P0     | 不受宿主页 CSS 影响，也不污染宿主页                                            |
| A4  | 支持单词 / 短语 / 句子 / 段落四种选中粒度                 | P0     | 段落选区上下文截取有上限（防止超长）                                           |
| A5  | 动态网页（SPA）选区处理                                   | P0     | React/Vue 页面选中后 DOM 变化不影响已快照内容                                  |
| A6  | 受限页面（chrome://、Web Store 等）兜底提示               | P0     | 注入失败时扩展图标弹提示，引导用手动输入                                       |
| A7  | 侧边栏手动输入框                                          | P0     | 支持粘贴任意英文 + 当前标签页上下文可选                                        |
| A8  | 双入口并存：浮动栏（全站）+ 图标激活本页                  | P0     | 浮动栏可配置全站开/关/站点排除清单；图标入口恒可用，受限页面自动降级为手动输入 |
| A9  | 不劫持页面快捷键与滚动                                    | P0     | 仅监听 selection 相关事件；Esc 关闭浮动栏可配置                                |

## B. AI 分析引擎（核心）

| #   | 功能                                                                             | 优先级 | 验收要点                                                          |
| --- | -------------------------------------------------------------------------------- | ------ | ----------------------------------------------------------------- |
| B1  | OpenAI 兼容 API 客户端（base URL / key / model / temperature / max tokens 可配） | P0     | 密钥仅存 chrome.storage.local，SW 内使用                          |
| B2  | 模式自动路由（单词/短语/句子/段落）                                              | P0     | 本地启发式预判 + LLM 返回 detected_type 校准；用户可手动覆盖      |
| B3  | 单词分析（基础信息/构词/语法作用/实际使用，见 PRD 案例 1）                       | P0     | IPA、词性、语境义、词根词缀、句中作用、近义对比、3 例句           |
| B4  | 短语与固定搭配分析（PRD 模式 B 七要点）                                          | P0     | 案例中 get through to / on steroids 类分析达标                    |
| B5  | 句子深度分析（直译/意译/意群/结构/语法/词汇/表达习惯/最终理解，八节结构）        | P0     | 四大验收案例全部达标；语法解释讲"作用与原因"而非贴标签            |
| B6  | 段落分析（大意/观点/句间逻辑/重要词组/复杂句/整段意译）                          | P0     | 不机械拆词；逻辑关系词（转折/因果/递进/举例）被显式指出           |
| B7  | 双轨翻译（结构直译 + 自然意译）                                                  | P0     | 所有句子级分析必含；讽刺/反问等言外之意单独标注                   |
| B8  | 结构化 JSON 输出 + 解析降级链                                                    | P0     | 严格解析 → 宽松提取 → 重试 1 次 → Markdown 纯文本兜底，四级不崩溃 |
| B9  | 流式输出（SSE → Port 转发 → 侧边栏渐进渲染）                                     | P0     | 首屏（概览节）先到先渲染；中断可停止                              |
| B10 | Prompt 独立管理（每模式一个模板 + 公共语言学研究纪律）                           | P0     | prompt 不散落业务代码；含"禁止编造词源/规则、标注不确定性"硬约束  |
| B11 | 网页上下文防注入（上下文作为数据包裹，不作为指令）                               | P0     | 含指令样文本的页面无法改变系统行为（有对抗样例测试）              |
| B12 | 用户英语水平/分析深度可配置并注入 prompt                                         | P1     | 设置项：入门/进阶/精通；深度：快速/标准/深挖                      |
| B13 | 请求超时/重试/取消/防重复点击                                                    | P0     | 超时可配默认 60s；重试指数退避；分析中禁重复发起                  |
