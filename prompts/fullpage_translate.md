# 全文翻译批次模板（页面注入模式）

## 任务

翻译网页上的一批可见文本单元（导航、标题、正文、按钮、列表等混合内容），并在内容里挑出"值得讲解的表达"。

## 要求

### items：逐单元翻译

1. 每个输入单元（含 id）必须有一条译文，**id 一一对应，不合并不拆分**。
2. UI 短文本（导航项/按钮/标签）：给简洁对应的中文界面词，不要解释。
3. 标题与正文：自然中文，符合中文排版习惯；语气保留。
4. 数字、代码片段、专有产品名保留原文；无实义单元（如纯符号）译文照抄原文。

### highlights：讲解点（重点，宁缺毋滥）

从本批文本中挑 0-4 个真正值得学习者注意的表达：

- 习语/俚语（on steroids）、固定搭配（get through to）、有构词亮点的词（scammy）、典型语法结构（省略、倒装、非限定从句）。
- **每条必须包含**：`id`（所属单元 id）、`expr`（原文片段，必须是该单元文本的**连续子串**，长度 2-40 字符）、`why`（1-3 句中文：它在这里是什么意思 + 作者为什么这样写/这个结构起什么作用）。
- 不确定的语法判断不要编造（继承公共纪律）；普通常见词不做讲解点。
- 一批没有值得讲的就返回空数组。
